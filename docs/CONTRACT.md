# MCP contract: PropInspect Deposit Laws

> Generated by `npm run contract` from the running server. Don't edit by hand; CI fails if it is out of date.
> Machine-readable version: [contract.json](contract.json).

Server `propinspect-deposit-laws` 0.1.0. Transport: stdio.

**Instructions the server gives the model:**

> Answers US security deposit questions (caps, return deadlines, penalties, move-in records) from PropInspect's reviewed guides for the 50 states. Answer only from tool results, never from memory. Always give the guide link and its review date, and say it is general information, not legal advice. If a tool says a place is not covered, tell the user plainly instead of guessing.

## Tools

### `get_deposit_rules`: Get a state's security deposit rules

Use when the user asks about security deposit rules in one US state: the deposit cap, the deadline to return it or send an itemized list, the penalty for wrongful withholding, or move-in condition records. Pass the two-letter state code (Nevada → NV). Returns the rules with a citation (guide link, review date, statute, disclaimer). If status is "not_covered", tell the user the place is not covered; do not answer from memory. Set include_faqs to true only when the user's question goes beyond the rules (for example cleaning, painting or normal wear and tear).

| Input | Type | Required | Description |
|---|---|---|---|
| `state` | string matching `^[A-Za-z]{2}$` | yes | Two-letter US state code, e.g. "NV" for Nevada or "NY" for New York. |
| `include_faqs` | boolean | no | Also return the guide's FAQ answers. Default false. |

Output: structured (`outputSchema` in contract.json) plus a text summary. Annotations: readOnlyHint=true, destructiveHint=false, idempotentHint=true, openWorldHint=false.

### `compare_states`: Compare security deposit rules across states

Use when the user wants to compare security deposit rules between 2 to 6 US states (for example a landlord with rentals in several states). Pass two-letter state codes. Returns one row per state with its own citation; places that are not covered are listed by their position in the input.

| Input | Type | Required | Description |
|---|---|---|---|
| `states` | array of string matching `^[A-Za-z]{2}$` (2–6 items) | yes | 2 to 6 two-letter state codes, e.g. ["CA", "NV"]. |

Output: structured (`outputSchema` in contract.json) plus a text summary. Annotations: readOnlyHint=true, destructiveHint=false, idempotentHint=true, openWorldHint=false.

### `list_covered_states`: List the states this server covers

Use when the user asks which states are covered, or before comparing many states. Returns every covered state with its guide link and review date.

No input.

Output: structured (`outputSchema` in contract.json) plus a text summary. Annotations: readOnlyHint=true, destructiveHint=false, idempotentHint=true, openWorldHint=false.
